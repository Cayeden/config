# Writing style

- Use plain formatting and phrasing.
- No headings unless the text is long enough to need them.
- No em-dashes, antithesis, filler, hype, or decorative emoji.

# Code comments

Keep comments to a minimum. Only add one when the code cannot explain itself, and keep it short.

# Commits and PRs

Never co-author commits or PRs. Do not add Co-Authored-By lines or generated-with footers.
